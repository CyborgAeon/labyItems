# Repository skills

When a task adds, changes, diagnoses, or reviews persistence, personal data, points apps, document links, search, account-sensitive caches, login, or account switching, read and follow `docs/skills/account-data-isolation/SKILL.md` before acting.

When a task creates, changes, diagnoses, reviews, or relocates C# type declarations, read and follow `docs/skills/csharp-type-organization/SKILL.md` before acting.

When a task creates, changes, diagnoses, or reviews a `DetailCardView` page, read and follow `docs/skills/detail-card-view/SKILL.md` before acting.

When a task adds, changes, or reviews glyph icons, read and follow `docs/skills/unified-glyph-icons/SKILL.md` before acting.

When a task creates, changes, or reviews MAUI XAML pages, controls, or resource dictionaries, read and follow `docs/skills/maui-xaml-style/SKILL.md` before acting.
